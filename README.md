# Мінна безпека

Освітній сайт про правила мінної безпеки для школярів і студентів: головні правила, дії на мінному полі, знаки небезпеки, довідник із 55 вибухонебезпечних предметів з описами, тест і екстрені номери.

**Побачив підозрілий предмет — не підходь, не торкайся, із безпечного місця повідом 101 або 102.**

## Структура

```
index.html   — уся сторінка (розмітка, стилі, скрипти)
fonts/       — шрифти Nastup і Fixel (SIL OFL 1.1)
img/         — 55 фото вибухонебезпечних предметів
.nojekyll    — вимикає обробку Jekyll на GitHub Pages
```

Сайт статичний, без збірки та залежностей. Щоб переглянути локально, відкрийте `index.html` через будь-який локальний сервер, наприклад `python3 -m http.server`.

## Джерела

- Фото: ДСНС України, «Найбільш розповсюджені вибухонебезпечні предмети».
- Описи предметів — навчальні узагальнення за матеріалами ДСНС України та UNICEF Ukraine.
- Статистика: Humanitarian Media Hub / Humanity & Inclusion, березень 2026.

Сайт не замінює інструктажу фахівців ДСНС і не є інструкцією з поводження з вибухонебезпечними предметами.
